# アーキテクチャ

## 概要

Tour-Rail は、Render にデプロイしやすいようにフロントエンドとバックエンドを分けた Web アプリです。

- フロントエンド: React + Vite + TypeScript + Leaflet
- バックエンド: FastAPI + OSRM 連携
- デプロイ構成: Render Static Site + Render Web Service

## データフロー

1. フロントエンドが `/config` を読み込み、初期表示設定を取得する
2. ユーザーが旅行者数と移動手段を選ぶ
3. ユーザーが地図上にスタート、ゴール、寄り道スポットを置く
4. フロントエンドがスポット一覧を `/route` に送信する
5. バックエンドが OSRM に問い合わせ、レスポンスを正規化する
6. フロントエンドが次を描画する
   - ルート線
   - スポットマーカー
   - 移動手段アイコン
   - ボードゲーム風のスポットカード

## フロントエンドの責務

- 旅行者数の状態管理
- 移動手段の状態管理
- 移動アニメーションの進行管理
- 遊びのある見た目とスマートフォンでの操作性
- ルート取得失敗時のフォールバック表示

## バックエンドの責務

- Render 用のヘルスチェック
- フロントエンド初期表示用の `/config`
- OSRM の詳細を隠蔽した `/route`
- localhost と Render 本番URL向けの CORS 制御

## 非対象

- データベース
- ユーザーアカウント
- 旅行プランの永続化
- AI による旅行ストーリー生成
